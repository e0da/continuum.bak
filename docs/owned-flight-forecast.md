# Owned flight radial forecasts

`OwnedFlightForecast` projects each retained region COM at constant inertial velocity against central-body spheres. It reports the finite-size surface approach, atmosphere edge and internal knots of the admitted altitude-linear environment table. These are **advisory model crossings**, not bounds on powered or gravitational trajectories. Numerical interval/surface guards remain authoritative. An earlier advisory crossing can cap a requested numerical interval; absence of a crossing never permits bypassing those guards.

`Capture(session, expectedStamp, horizonSeconds)` produces an immutable, cold snapshot. `Capture(descriptor, read, horizonSeconds)` supports retained presentation reads. Rows are returned by value, ordered by delta, stable region ID and kind. `FirstPositiveDelta` is the horizon when no row exists; `HasPositiveCrossing` distinguishes that case. The snapshot binds the full physical stamp, context SHA, coordinate frame, retained origin and universal time. Session-created snapshots use `RequireCurrent`; descriptor-created snapshots use `RequireMatches` against their retained read/descriptor, rather than claiming current live authority. Advancing, rebase, topology change or replacement invalidates a session snapshot. Forecasts are derived observations and are not checkpointed.

`TryFirst(session, read, horizon, out row)` is the allocation-free scheduler query. It admits the session's current read descriptor, visits regions, and binary-searches the radial interval for possible atmosphere knots. A small coordinate-rounding expansion of this search range prevents a knot from being excluded solely by range arithmetic; it is not a physical uncertainty allowance. Crossings are still recomputed from the supplied position/velocity. The finite-size extent matches the conservative session recipe: maximum body-local radius plus acquired vessel radius, then COM offset magnitude. This represents a conservative spherical envelope, not terrain or contact geometry. The hot query uses the session cached extent accessor, admitted against the current read and current COM; cold snapshots reconstruct the same recipe.

The crossing solver scales geometry and speed, evaluates the discriminant with transverse geometry, and uses the cancellation-safe paired quadratic roots. It selects the first strictly positive root within the finite horizon (maximum 7200 seconds). Tangency is a distinct result. A point currently on the sphere does not emit a zero-time event: inward motion can report its later exit; outward motion has no future root. The surface query excludes outbound exits. An already reached surface guard is reported separately in the cold snapshot and must be handled by the existing physical guard, not a zero-step loop.

Arithmetic remains double precision, without widening any existing motion budget. Nonfinite/overflowing observations reject explicitly. A discriminant near machine precision can be uncertain in the geometric model; the result has no certified-error label. No arbitrary acceleration, control change, moving surface, atmospheric variation beyond the acquired radial table, terrain, rotational shape or collision prediction is bounded here.

The focused portable checks cover independent radial roots, inside exits, tangent contact, current-boundary no-zero behavior, misses, stationary motion, large coordinates, two-region atmosphere/knot/surface observations, source immutability, stale rejection and rebase invariance. Source acceptance does not establish actual captured-craft or native scheduler qualification. Root owns builds and the actual consumer evidence.

Retained matching also binds an opaque bank identity. Equal stamps/context/origin
in a foreign reconstructed world do not make its read the same forecast source.

thermal represented-clock deadlines and partial automatic coast semantics.

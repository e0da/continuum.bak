# Solar and body occlusion replay

The capture is an intrusive diagnostic of two original scheduled passes, not a performance treatment. Set `CONTINUUM_CYLINDER_OCCLUSION_CAPTURE` to an absolute, nonexistent JSON file in an existing private directory. The flight owner calls `CylinderOcclusionCapture.Create(arguments, runId, capturing)` before narrow FlightIntegrator attribution, then disposes attribution before this capture. Disposal removes owned hooks before writing. No game objects, thermal state, cylinder state, scheduling, or original exceptions are replaced.

One complete solar pass and one complete body pass must begin and end inside the owner's capture window. Missing, interrupted, foreign, overflowing, or changed-topology coverage is invalid. The recording binds run ID, PID, vessel GUID, original assembly SHA/MVID, context frame, monotonic clocks, UT, direction, and persistent part IDs with supplemental live object identities. The bound is 1,024 rows and 523,776 reached pairs per pass. Row and tape storage is allocated before callbacks; JSON construction and file writes occur after cleanup. Capture clocks are charged observer cost and are not candidate performance evidence.

## Original boundary

The two pinned FlightIntegrator methods have the same scalar fold. They retain independent lists, multipliers, cylinders, directions, and scheduled invocation epochs. The solar direction is the current sun vector; the body direction is negative vessel up. They cannot be combined into one scheduled pass without changing when each result becomes visible.

Each original method updates projected geometry, conditionally sorts ascending by maximum projection dot, and traverses descending. It initializes the first row's multiplier to one and publishes its cylinder. Every later row starts at one, subtracts each previously accepted cylinder's rectangle fraction in insertion order, sets zero and stops at a value at most 0.001, then publishes a cylinder only if its multiplier remains positive. Publication uses the complete original row geometry, without scaling the cylinder by remaining exposure.

The fraction uses float offset-plus-rectangle coordinates before double rectangle arithmetic. It checks disjoint intervals and zero target area, otherwise divides clamped intersection area by target rectangle area. The original scalar turns a NaN result into zero and may log the configured warning. Preserve this branch, subtraction order, signed zeros, cutoff, and accepted-cylinder order; summing fractions or unioning rectangles is a different algorithm.

The capture transpiles the exact original caller's two cylinder-Setup calls and one scalar-call site to wrappers that invoke those original operations once. This avoids relying on interception of small inlined callees. It records initial order before projection; sorted projected rows at the first Setup; reached row/cylinder/result tape; every original Setup output; and final multipliers. Equal-depth ordering is captured rather than assumed stable across runtimes. Thermal-graph replacement within a pass invalidates coverage.

## Offline oracle

Use the existing original-assembly ConvectionBench admission and reconstruction precedent. Admit the same original assembly hash/MVID and exact declared scalar/Setup identities. Reconstruct thermal data and occlusion rows without invoking Unity object constructors, then invoke original `GetCylinderOcclusion` and `OcclusionCylinder.Setup` under an independently written ordered fold. Compare every reached pair, its double bits, every accepted cylinder's row and field bits, and every final multiplier's double bits against the actual recording. This is a post-projection scalar oracle; it does not qualify reconstructed transform projection or physics.

The recording schema is `continuum-cylinder-occlusion-recording/v1`. Rows are ascending; tape `row` and `cylinderRow` refer to those indices. `*Bits` fields encode IEEE double bits as signed 64-bit integers. Float rectangle/cylinder fields are admitted finite and serialized round-trip. `initialOrder` stores pre-projection persistent IDs. The `passes` array has separately named solar and body records. Accepted cylinder fields include projected center, negative rectangle center, extents, projected radius, and nose dot; scalar rectangle coverage only consumes offset and extents, but the other published fields remain obligations.

Independent falsifiers are a zero-area/touching/disjoint rectangle; overlapping cylinders whose ordered subtraction reaches the cutoff before a later candidate; equal-depth rows whose accepted set depends on order; and a NaN scalar path with the original warning setting. Missing or reordered pair calls and an identity-correct but changed cylinder field must fail even if final multipliers happen to match.

## Next representation

Retain main-thread ownership of live transforms and drag-cube inputs. A coherent next projection boundary snapshots each part's matrix and weighted bounds once at the scheduled invocation, computes the common direction-to-up quaternion once, and projects a contiguous row slab with the original float/double operation order. World-space corners can be shared within that invocation, not across different scheduled solar/body epochs unless their actual pose and drag dependencies are proved unchanged. The complete fold then operates on resident rows without repeated object/native transform reads. Projection capture and an independent original projection comparison are still required before replacing that owner; scalar replay alone cannot establish it.

# Shared aerodynamic step context

`CONTINUUM_AERO_STEP_CONTEXT=verify|query|compare` enables a private experiment around the original `FlightIntegrator.Integrate` root. Absent means off. The experiment preserves recursive part order, directional curves, weighted arithmetic and Unity force publication. It replaces nine reached Mach-curve callsites with six lazy role slots, reset for every root. Each slot retains the original first-use evaluation; reuse requires the same wrapper and exact float input bits.

`verify` records two captured roots, compares each reused value bitwise with the original evaluation at that same callsite, and returns the original value. It does not run a second force calculation. This verifies reached values under the admitted ownership lease; it is not a complete stock/candidate performance comparison. `query` returns reused values and records complete context-plus-root costs, including admission, reset, lookup and native publication. First-admitted-root costs are retained outside capture too. Installation and cleanup are separate costs; surrounding FixedUpdate work and complete frames remain separate measurements.

The experiment pins the original assembly, instruction shapes, reachable managed graph and actual lift-provider dispatch once. A reserved frozen patch/managed ownership lease is checked at installation and cleanup. Root guards check exact bound topology, current part/cube/provider owners and six curve aliases without repeated Harmony or reflection scans. Exact stock `Part` and `CompoundPart` are supported through inherited nonvirtual aero accessors; custom subclasses and absent cube owners are unsupported. Changes between roots can be read afresh; concurrent or within-root curve, patch or native mutation remains outside this experiment's scope.

Admission failure runs the original root without reuse. Unexpected in-root input, owner or result disables further reuse and invalidates the experiment. Already-applied native forces cannot be rolled back, so the report does not claim all-or-none recovery. Completion requires original callsite coverage, no mismatches or observer errors, and observed removal of owned hooks.

Reuse counts alone do not establish a speedup. Compare compatible complete flights with the same helper and frozen inputs, varying only the declared environment mode. Parent/child timing rows overlap and must not be summed. A negative or inconclusive complete-flight result keeps the treatment experimental and off in ordinary launches; it does not establish absent local benefit.

`compare` measures the local owner through common instrumentation. It selects each captured root before timing by a fixed index: even control-original, odd query. Both arms retain admission, slot initialization, role/key checks, lookup/counters and complete window bookkeeping. On control hits the original evaluation runs once and its value is returned, without verification comparisons or per-evaluation clocks. Only query hits return cached values. Pre-capture roots use control-original. There is one original force calculation per root. Completion requires both arms, contiguous alternation, balanced counts and complete per-arm evaluation/cleanup witnesses. Adjacent roots have different physical states; a mixed flight's FPS is not a candidate FPS comparison. Retain all adjacent pairs and cold/bookkeeping costs. The control includes wrapper tax and does not measure untouched-stock root cost.

## Selected native result

The 512-part frontlit atmospheric fixture reached all nine sites and six roles. Two original-return roots checked 30,828 reused values against the original evaluation with zero bit mismatches, faults or fallbacks. The original force calculation ran once per root. A separate query flight completed 151 captured roots: six original evaluations per root and 2,327,514 reused values, with all owned hooks removed.

One clean baseline/query pair used the same helper, frozen profile and 21 inputs. Both captured 3.02 simulated seconds at normal time, 1920×1080, uncapped with VSync disabled, and stable topology. Their starting states differed by one physics step. Mean frame cost was 25.524 → 24.936 ms (39.18 → 40.10 FPS); p95 was 36.942 → 29.468 ms and p99 46.964 → 45.678 ms. Managed fixed work was 7.137 → 7.274 ms per step. This short pair does not establish an attributable gain or tail improvement, and lacks an equally instrumented original root control. Local benefit is unresolved; the candidate and numerical proof are retained. No unchanged frame-pair repetition is needed before measuring that boundary or choosing the larger transaction.

Query context plus original root cost averaged 1.695 ms, including 0.016 ms admission, 1.662 ms root execution and prefix/end bookkeeping. Installation took 71.352 ms, cleanup 53.099 ms, and the first uncaptured invocation 7.259 ms. These are candidate scopes, not a clean original-root comparison. Full frames include their overhead. CPU/RSS and GPU execution were not sampled; FinishFrameRendering is not GPU duration. Actual baseline and query images show the craft, atmosphere, UI and live portraits; long booms extend outside the frame.

The actual assembly metadata and opcode/operand rewrites also passed a private standalone ARM64 Mono preflight without booting KSP. It admitted four shapes and nine sites. This fast loop does not execute the rewritten delegates, preserve original branch labels, install native detours or prove force behavior; those require separate live evidence.

The matched local comparison passed in one later flight: 76 control-original roots and 75 query roots, all 151 fully enclosed, with zero faults/fallbacks and complete cleanup. Every root reached 15,420 callsites; control evaluated each one, query evaluated six. The 75 adjacent pairs saved 0.2651 ms mean and 0.2232 ms median in complete context cost; 68 pairs saved time and seven lost time. Paired mean cost was 1.9234 → 1.6583 ms, a 13.78% reduction within this instrumented owner. Root-only mean saving was 0.2361 ms. The first control's 1.6721 ms bookkeeping outlier remains included. All pairs have different Mach input bits; fixed control-first order is a confound. This is a bounded local positive worth retaining, not an FPS or untouched-stock cost comparison. It resolves why the earlier complete-flight inconclusiveness cannot reject the component.

The larger replacement boundary is one root-level drag transaction: capture mutable inputs into rows, fuse direction and six-face reduction, and publish outputs in original order. The opt-in source candidate below implements this managed boundary. Native execution would still need to earn its capture, transfer and publication costs. Unsupported providers and Unity force ownership remain explicit boundaries.

## Complete drag transaction

`CONTINUUM_AERO_DRAG_TRANSACTION=1` extends the same `verify|query|compare` context; absent keeps the existing Mach-only experiment. It replaces the one reached `FlightIntegrator.UpdateAerodynamics` call to `DragCubeList.SetDrag`, through the existing aero transpiler. There are still four patched methods and nine pinned original Mach sites, plus one separately counted SetDrag callsite. SetDrag itself has no Harmony patch. The original force calculation, recursive part order, environment calculation, provider dispatch and native force calls remain in place.

Admission checks the bound cube owners, six-element nonnegative finite face arrays, current drag/lift direction-curve aliases and the stock axis basis once per root. `None` cubes bypass these additional array/provider checks and retain the original no-call behavior. Reached calls copy the 18 face inputs into temporary value structs. A local five-role cache shares the root's six Mach slots; it loads only reached roles, using the original float-normalized branch and first-use order. The fused reduction comes from the existing complete SetDrag donor and uses double accumulators. Direction and weighted-drag curve evaluations remain real original calls. The complete 13-component CubeData is calculated in temporary storage, checked for finite output, then published once at the original callsite. Allocation, admission, copying, role loads, calculation, publication and bookkeeping are inside the complete context clock.

The numerical contract remains the donor's relative error `abs(candidate-stock) / max(1, abs(stock)) <= 2e-5` for every component, including both vectors and all seven scalars. This is tolerance equivalence, not bitwise CubeData or trajectory equivalence. Mach reuse retains its bitwise witness. Nonfinite direction-curve results, invalid directions, zero surface multipliers and nonfinite outputs take the original SetDrag path before candidate publication and invalidate the experiment. No tolerance is widened. The axis array and patch graph are installation/cleanup leases; replacement of that static array or concurrent/within-root input, curve or patch mutation remains unsupported. Root checks inspect the admitted array's values without reflection; cleanup also checks its identity.

`verify` performs two captured original-return roots. At each reached call, original SetDrag publishes its output, then a donor shadow computes from the same unmutated input arrays and compares every component. The stock CubeData stays authoritative. This repeats managed drag arithmetic only; it never repeats native forces. In `query` and `compare`, two complete qualification roots run this same original-return witness outside capture before any substitution. `ReadyForCapture` exposes their completion, and `QualificationFailed` exposes a failed experiment; the caller waits within a bound while original physics progresses. The driver does not assume a fixed number of physics roots per rendered yield. Capture starting early is invalid. `dragQualificationRoots`, `dragQualificationCalls` and `dragQualificationContextTicks` retain the proof and its complete context cost, while `dragWarmupWaitStartedTicks/EndedTicks` let the caller retain actual waiting time. First-invocation treatment and first-substitution context cost are retained separately.

After qualification, captured `query` roots publish only candidate CubeData. Captured `compare` roots alternate original SetDrag/control evaluations and candidate SetDrag/Mach reuse, with common admission and complete window accounting; they contain no shadow work or verification clocks. `setDragCalls`, `originalSetDragCalls`, `candidateSetDragCalls`, `shadowSetDragCalls` and `verifiedSetDragCalls` identify actual work. Original face/surface entry counts describe only original method execution; candidate rows are counted separately. The final gate rejects missing qualification, mixed publication, failed coverage, mismatches or cleanup failures. Unsupported root inputs use the whole original root before reuse; a later unexpected call failure falls back before that call's CubeData publication. Earlier native force effects cannot be rolled back.

The actual-helper fast metadata/resource gate passed: four original shapes, nine Mach sites, one SetDrag seam, the actual face field and process-report serialization. This does not prove branch labels or detours by itself. Two distinct native flights then supplied original-return numerical proof and a matched local comparison with an aligned intrusive diagnostic. Both used the same helper and frozen 512-part frontlit atmospheric input family. Actual craft, atmosphere, UI and portraits rendered; some booms were outside the image.

Verify run `1791763128-46520` checked 996 complete 13-component outputs in two original-return roots. Maximum relative error was `2.3545810729355034e-7` under the unchanged `2e-5` gate; 35,808 Mach reuse checks were bitwise equal. Faults, mismatches, fallbacks and safety stops were zero, and owned hooks were removed. This flight includes shadow arithmetic and is not a performance arm.

Compare run `1791763411-48980` completed 501 enclosed roots: 251 control and 250 query, with 124,998 original SetDrag calls and 124,500 candidate publications. Two original-return qualification roots outside capture checked another 996 outputs, maximum relative error `2.3569757643967026e-7`. Captured shadow calls and verification clocks were zero. All coverage, parity, cleanup and numerical gates passed.

All 250 adjacent pairs are retained, plus the final unpaired control. Complete context cost averaged **2.1598408 -> 1.9305564 ms**, saving **0.2292844 ms mean / 0.2426 ms median**, or **10.6158%** of the measured owner. There were 204 positive and 46 negative pairs; root-only saving averaged 0.2212116 ms. Independent review reproduced every cost equation and counter. Only one pair shares Mach bits; physical states still differ. Fixed control-first order, common wrapper tax, first-use/bookkeeping costs and the intrusive native sampler remain confounds. These within-flight observations are not independent repetitions.

Classification: retain a bounded local positive; ordinary deployment remains off. This does not establish an incremental gain over the earlier Mach-only experiment, untouched-stock root cost, a clean FPS improvement, long trajectory equivalence or arbitrary mod coverage. The [aligned process diagnostic](flight-process-diagnostics.md) chooses the next unresolved owner without repeating this unchanged workload.

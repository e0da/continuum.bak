# Convection fold replay

This private-reference tool reads bounded `CCV1` snapshots and calls the pinned original KSP `OcclusionCone.Setup` and `OcclusionData.GetShockStats` methods. It does not launch Unity, install a plugin, or distribute KSP assemblies/source. Set `KSP_MANAGED` to the owner-provided Managed directory; the original assembly SHA256, MVID, declaring types and three method tokens are enforced.

```sh
KSP_MANAGED=/private/KSP/Managed dotnet build tools/KspContinuum.ConvectionBench
dotnet tools/KspContinuum.ConvectionBench/bin/Debug/net8.0/KspContinuum.ConvectionBench.dll --admit
dotnet tools/KspContinuum.ConvectionBench/bin/Debug/net8.0/KspContinuum.ConvectionBench.dll --falsify
dotnet tools/KspContinuum.ConvectionBench/bin/Debug/net8.0/KspContinuum.ConvectionBench.dll --verify-stock /private/frames.ccv
dotnet tools/KspContinuum.ConvectionBench/bin/Debug/net8.0/KspContinuum.ConvectionBench.dll --observe /private/frames.ccv index /private/new-receipt.json
```

`--observe` performs exactly two complete recording folds in a fresh process, without a full-recording warmup. Treatments are `stock`, `index`, `stock-delegate`, `tan` (dictionary), and `tan-two-slot` (two exact angle-bit keys; other angles use original `Math.Tan`). Receipts use CreateNew, bind input/original/tool/Core digests, record runtime/architecture/clock, and gate every final multiplier and accepted cone field bitwise against the captured outputs. Run `--verify-stock` before using those captured outputs as the baseline oracle. No tolerance relaxation is provided.

Fold time includes fresh original input objects, global reset, candidate index construction/insertion/query or tangent cache reset/lookup, original ordered scalar calls and Setup, and result materialization. It excludes projection, FX camera, game publication, receipt encoding and output comparison. Cold JIT is included in the first observation; admission/delegate preparation is reported separately. Fallback restarts the full stock fold and its partial work remains charged, although returned counters describe the completed stock fold.

The index preserves stock accepted-cone order and conservatively unions rectangle and shock-circle receiver envelopes. It widens bounds for original binary32 addition/subtraction and squared-distance rounding. Admission uses input geometry/globals and freshly produced cones; recorded expected outputs are only an oracle. Nonfinite/unsupported input or cone values, and nonpositive/nonfinite intermediate temperature/coefficient multipliers, restart stock enumeration. This is necessary because an apparently disjoint scalar call still executes arithmetic involving cone multipliers and can normalize signed zero or propagate NaN. Dense envelopes can retain nearly every pair, making indexing more expensive.

Tangent treatments emit detached delegates from the pinned original `GetShockStats` IL using the pinned Harmony package. The treatment changes its one radius call; the stock delegate leaves every instruction unchanged. This avoids unsupported native Harmony detours on .NET ARM64. Radius adaptation retains original subtraction, field-read and multiplication/addition order; the remainder of KSP's scalar body is neither authored nor copied here. Dispose drops the delegate/cache and verifies the original patch graph remains untouched. Zero cache requests or zero hits fail coverage.

The retained four-frame, 512-part workload matched stock bitwise on .NET 8 ARM64 despite originating in Unity 2019 Mono/Rosetta x64. Two observations rejected both the dense index (50.7513/44.9620 ms versus direct stock 27.2496/21.4013) and tangent dictionary (35.8185/31.6405 versus unchanged delegate 19.2006/15.9354). Two fixed slots reduced overhead (21.2418/19.0645) but still did not win. Each tangent observation had 366,292 hits and eight misses; the index removed only 8,857 of 366,664 executed pairs. The two-slot binary differs from the recorded stock-delegate binary, and the substantial direct/delegate timing difference limits comparisons further. Exact timed two-slot and final tool binaries are retained privately; earlier executed bench binaries are unavailable and their receipts retain only identity hashes. These are fold-only, host-specific observations, with no live FPS or production equivalence claim.

Focused falsifiers cover sparse elimination, shock-only influence, nonfinite zero-times-NaN stock fallback, signed-zero fallback, binary32 distance boundary admission, nonfinite accepted-cone rejection, exact signed-zero/NaN keys, and uncached third-angle behavior. Original projection/order capture and all native qualification remain owner responsibilities.

`--census FRAME_FILE NEW_REPORT_FILE` folds the recording once with detached read-only original-IL hooks. Admission additionally pins the complete `GetShockStats` body SHA256, eight local types, 155-instruction shape, actual circle-return site, and coefficient-local mappings at the boundary before reference multiplier writes. The receipt records exact coefficient-bit histograms, no/partial/full/other geometry counts, actual circle calls separately from the full-cylinder branch's assumed full shock, and each row's reached/cutoff/reset positions. Snapshot sequence, universal time and Mach bind the flight state. Histogram capacity is bounded; uncertain method/slot/context shape fails instead of guessing. No timing is collected and no original IL/body is stored in source or receipts.

The single retained census reached 366,664 pairs and matched every recorded output bit. It observed 117,387 pairs with neither overlap (32.015%), 2,350 partial shock intersections (0.641%), and 246,927 full-shock resets (67.344%). A reset requires original effective-shock bits `3ff0000000000000` and remaining-weight bits `0000000000000000`. Across frames, 509/509/510/510 of 512 rows reached a reset, with 3,210 subsequent calls in total; all 397 cutoffs occurred on the row's last reached reset. The cutoff-triggering pair is included, while uncalled later pairs are excluded. These observations motivate separating dense geometry discovery from a reset-aware ordered fold; they do not authorize skipping area-prefix cutoffs, changing accepted-cone propagation, or assuming finite/signed-zero arithmetic equivalence.

`--verify-reset FRAME_FILE NEW_REPORT_FILE` proves the reset candidate against the captured oracle without timing. `--falsify-reset` runs only the new reset counterexamples. `--observe FRAME_FILE reset-stock|reset NEW_REPORT_FILE` performs two complete folds of the unchanged admitted delegate or the candidate. Both use the same delegate field directly, without a per-pair context guard. All fresh inputs, globals, buffers, certification, fallback work, original Setup and output construction are charged. Delegate construction is reported separately. No recorded expected multiplier, area or accepted cone feeds candidate admission or computation.

The candidate mechanically extracts two functions from the pinned original 155-instruction body. The forward function retains the original binary32 rectangle transforms, normalized cylinder threshold `.99`, and final area expression, while omitting circle and thermal arithmetic. Its original ordered area product identifies the exact reached prefix, including the cutoff-triggering pair. The second function retains all original geometry through its coefficient locals and returns the original effective cylinder/shock values. Reverse queries stop at the last reached exact full shock. The unchanged original delegate evaluates that reset and every later reached pair, followed by original Setup and ordered cone publication. No KSP scalar body is copied into the tool.

Reset admission is deliberately bounded. Mach is finite in `(1,1e10]`; projection floats have magnitude at most `1e10`; rectangles have ordered endpoints and nonnegative extents; projected radius is zero or in `[1e-6,1e10]`. Scalar projection magnitudes, fineness and globals have explicit limits in `ResetKernel`. Heat/coefficient globals and freshly published cone coefficients must lie in `[0,1]` and cannot be negative zero. Every original shock-radius endpoint at the frame's smallest/largest centroid dot must be finite with magnitude at most `1e20`; the ordered affine original radius function is monotone between those endpoints. Original thermal diagnostic logging must be disabled. Unsupported input or newly produced state restarts the entire original frame on fresh inputs. Shape/pin failures are errors, and oracle differences fail rather than trigger fallback.

The finite-prefix certificate does not assume the partial-lens result lies in `[0,1]`. Bounded float distances and radii prevent geometric overflow; positive recipient radii prevent denominator underflow. Original NaN lens intermediates retain their original zero fallback, with logging disabled. A loose absolute shock bound is `B=8*(maxAbsShockRadius/minPositiveRecipientRadius+1)^2`, also covering signed radii and unbounded-by-one partial quotients. With unit-bounded published coefficients and normalized cylinder in `[0,1]`, a magnitude envelope grows by at most `8*(B+4)` per unknown pair. The implementation adds one exponent bit per step and limits spans below exponent 880. Sparse exact original full-shock anchors reset the envelope to four; spans lacking an anchor use their actual original shock coefficients and a conservative recurrence. Exhausted/nonfinite envelopes fall back. This establishes finite skipped accumulators, including intermediate products and sums.

At a certified reset, original remaining weight is positive zero. Finite prior values can contribute only signed zero. The retained current pair has nonnegative cylinder/shock weights and nonnegative coefficients without negative zero; its ordered additions normalize any zero-sign difference. Thus replacing a certified finite prefix by the initial unit accumulator preserves the reset's bits. The original current-pair and tail arithmetic still runs unchanged. Zero times NaN/infinity is not neutral: the poison falsifier demonstrates that full shock still propagates it, and unsupported inputs take stock fallback. Additional falsifiers cover cutoff before a later influential shock, original cylinder threshold before the circle branch, negative zero, float-distance overflow domain and enabled logging.

A native seam would run after original projection/sorting and replace only the ordered convection fold. It must publish one complete result and cone sequence under one owner, and run original stock on untouched state if admission fails. This tool uses fresh shadow inputs, so fallback cannot leak partial candidate state. Transferring that transaction to live `PartThermalData`, preserving diagnostics and measuring the complete live cost are unresolved owner gates; these offline receipts establish no native FPS gain or installation readiness.

`--attribute-reset FRAME_FILE NEW_REPORT_FILE` captures one complete reset fold with exclusive row-phase timestamps and the unchanged recorded oracle. The retained attribution measured `10.0684` ms in the rectangle/area prefix, `3.2978` ms in finite-prefix certification, `0.8585` ms in reverse reset discovery and `0.4622` ms in original reset/tail arithmetic. Inputs/globals measured `2.4505` ms, mostly in the first frame. Timestamp overhead and cold JIT are unqualified; this single intrusive observation chooses an architectural boundary, without establishing treatment performance.

`--verify-query FRAME_FILE NEW_REPORT_FILE`, `--falsify-query` and `--observe-query-matched FRAME_FILE NEW_REPORT_FILE` qualify the area-query alternative. It builds one static tree of the current frame's projected receiver rectangles. Each freshly accepted area-changing cone queries that tree with a conservative binary32-addition envelope and appends its accepted index to future recipients. Appending preserves stock cone order; inclusive boundaries retain touching candidates. Unit-area cones need no area query, and disjoint receiver rectangles have original cylinder zero. Remaining area queries use the original extracted expression and ordered area product. Cutoff records the original accepted index, including neutral gaps, before reverse reset/certificate discovery. The latter still uses exact original geometry, filling cylinder coefficients lazily; no shock influence is spatially pruned.

The unit-area omission is an IEEE binary64 argument within the admitted domain. Effective cylinder is in `[0,1]`: original ordered finite rectangles yield a nonnegative ratio, and the original `.99` branch normalizes every ratio at or above that threshold to one. For `c>=.5`, subtracting `c` from one is exact by Sterbenz's lemma, and adding it back yields exactly one. For `0<=c<.5`, the first rounding error is at most `2^-54`; the final sum lies within the rounding interval for one, whose lower midpoint tie selects even one. Multiplication by exact one preserves `c`, including subnormals. Thus the original unit-area expression returns exact positive one. The running area starts positive and is an ordered product of admitted nonnegative factors; multiplying by exact one preserves its bits. A neutral pair cannot newly trigger cutoff because the preceding stock pair would already have stopped the fold. Conservative disjoint rectangles return positive cylinder zero and likewise exact area one. All omission depends on the existing finite/logging domain; no identity is assumed for NaN or infinity.

Three new witnesses exercise only this change: the extracted original area expression at eleven tiny/zero/half/one boundaries plus NaN/infinity counterexamples; omitted neutral cones surrounding an area cutoff; and a binary32 addition boundary that would be missed by an unpadded double-space query. The area-expression witness injects only the coefficient local into a detached pinned IL extraction, retaining the original final area instructions; it never feeds the real replay. Existing reset/index/cache fixtures and timings were not repeated.
